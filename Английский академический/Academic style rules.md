#англ_академ 
1) Formal vocabulary
	Examples:
	- dad -> father
	- like... -> such as...
	- lots -> significant number
	- 3 -> three (all numbers under 10 need to be expressed as words, except with measurement units or mixing words and numbers in one sentence)
2) Formal words instead of multiword verbs
	Example:
	- go up -> increase
	- talk about -> discuss
	- get better -> improve
	- get worse -> deteriorate
	- bring up -> raised
	- look up to -> admire
	- get in to -> enter
3) Full form of verbs
	Examples:
	- don't -> do not
	- can't -> cannot
	- won't -> will not
4) Formal grammar structures
	Examples:
	- Bad: The environment is increasingly polluted. This is a global concern.
	- Good: The increasing pollution of the environment is a global concern. (Nominalisation - Noun phrase)
	- Bad: Note-taking is an important skill for EAP students. It is difficult to master.
	- Good: Note-taking, which is an important skill for EAP students, is difficult to master. (Complex grammar - Relative clause)
5) Statements
	Examples:
	- Bad: What were the reasons behind the decline?
	- Good: There were four main reasons for the decline.
	- Bad: How are written and spoken English different?
	- Good: Written English is different from spoken English.
6) Impersonal phrases
	Avoid personal pronouns and adverbs to show feelings
7) Be precise
	Use exact figures:
	- factors
	- issue
	- topic
	- aspect
	- reason
8) Cite your sources
9) Tentative language
	Avoid absolute statements.
	Good:
	- possibly
	- probably
	- may
	- might
	- appears to
	- seems to
	- tends to
	Bad:
	- always
	- will
10) Appropriate transitions
	Avoid numbering bullets, basic transitions.
	- Cause -> Effect
	- Main idea -> Example
	Examples:
	- as a result
	- for example
	- furthermore
	- in conclusion
