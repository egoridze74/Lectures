#проекты 
Проект - комплекс мероприятий, направленных на реализацию одной задачи. Формируется 1 раз для выполнения 1 задачи.

### По масштабу
- Малые - небольшая команда, короткие сроки, ограниченный бюджет;
- Средине - задействованы несколько отделов, бюджет выше, сроки - от нескольких месяцев до года;
- Крупные - масштабные проекты, которые могут длиться очень долго

### По сложности
- Простые - четкие требования, известные технологии, предсказуемый результат;
- Сложные проекты - высокая неопределенность, необходимость инноваций, множество внешних факторов (например, разработка ИИ-систем с нуля);
- Мегапроекты - вовлечены тысячи людей, множество организаций, высокие риски

### По срокам
- Краткосрочные - до 6-12 месяцев;
- Среднесрочные - от 1 до 3 лет. Например, внедрение ERP;
- Доолгосрочные - более 3-5 лет

### По классу
- Монопроект - один самостоятельный проект;
- Мультипроект - группа взаимосвязанных проектов с общей целью;
- Мегапроект - масштабный стратегический проект с участием нескольких организаций

### По виду (цель)
- Инвестиционные - хотим получить денег;
- Инновационные - хотим получить технологии;
- Научно-исследовательские - хотим получить новые знания;
- Учебно-образовательные - повышение квалификации челов;
- Смешанные - что-то между

### По типу (сфера)
- it-проекты;
- Инфраструктурные - строительство, ремонт, модернизация;
- Трансформационные - изменение бизнес-модели;
- Продуктовые и маркетинговые - запуск продукта, рекламы;
- Социальные - благотворительность, экология, образование
