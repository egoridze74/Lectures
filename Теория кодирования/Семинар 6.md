## Построение альтернантного кода
$\mathbb{F}_4: C = GRS_2(a, v)$
$A = C \cap \mathbb{F}_2^4$
$n = 4, \ r = n - k = 2$

$\mathbb{F}_4 = \mathbb{F}_2[\alpha]$
$\alpha^2 + \alpha + 1 = 0$
$\alpha^2 = \alpha + 1$
$\alpha^3 = \alpha^2 + \alpha = 1$
$\beta = \alpha + 1 = \alpha^2$
$\alpha + \alpha = (1 + 1) \alpha = 0$

$\alpha + 1 = \beta$
$\alpha \cdot \beta = 1$
$\alpha^2 = \beta$
$\beta^2 = \alpha$
$\alpha^{-1} = \beta$

Зададим базис:
$0 \implies \begin{pmatrix} 0 \\ 0 \end{pmatrix}$
$1 \implies \begin{pmatrix} 1 \\ 0 \end{pmatrix}$
$\alpha \implies \begin{pmatrix} 0 \\ 1 \end{pmatrix}$
$\beta \implies \begin{pmatrix} 1 \\ 1 \end{pmatrix}$
$a = (0, 1, \alpha, \beta)$
$v = (1, \alpha, \beta, 1)$
