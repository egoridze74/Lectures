### Алгоритм декодирования
Вход: $\alpha, k, y$
1. Найти пару $(E_1, N_1)$ с $\deg E_1 \leq t, \ \deg N_1 \leq t + k - 1$ и $E_1(\alpha_i) \cdot y = N_1(\alpha_i)$
2. Если $E_1$ не делит $N_1$ - отказ
3. Положить ${f} = N_1 / E_1$
4. Вернуть $ev({f})$

### Задача 1
$RS_2(\alpha)$ - код Рида-Соломона
$\alpha = (1, 2, 3, 4, 5, 6)$
$y = (0, 6, 4, 6, 6, 3)$

$n = 6, k = 2$
$d = n - k = 1 = 6 - 2 _ 1 = 5$
$t = \lfloor \frac{d - 1}{2} \rfloor = \lfloor \frac{5 - 1}{2} \rfloor = 2$
$\deg E_1 \leq 2$
$\deg N_1 \leq 3$
$E_1 = e_0 + e_1x + e_2x^2$
$N_1 = n_0 + n_1x + n_2x^2 + n_3x^3$

1) $(e_0 + e_1 + e_2) \cdot 0 = n_0 + n_1 + n_2 + n_3$
	$6n_0 + 6n_1 + 6n_2 + 6n_3 = 0$
2) $(e_0 + e_1 \cdot 2 + e_2 \cdot 4) \cdot 6 = n_0 + n_1 \cdot 2 + n_2 \cdot 4 + n_3 \cdot 8$
	$6e_0 + 5e_1 + 3e_2 = n_0 + 2n_1 + 4n_2 + n_3$
3) $(e_0 + e_1 \cdot 3 + e_2 \cdot 9) \cdot 4 = n_0 + 3n_1 + 9n_2 + 27n_3$
	$4e_0 + 5e_1 + e_2 = n_0 + 3n_1 + 2n_2 + 6n_3$
4) $(e_0 + e_1 \cdot 4 + e_2 \cdot 16) \cdot 6 = n_0 + 4n_1 + 16n_2 + 64n_3$
	$6e_0 + 3e_1 + 5e_2 = n_0 + 4n_1 + 2n_2 + n_3$
5) $(e_0 + 5e_1 + 25e_2) \cdot 6 = n_0 + 5n_1 + 25n_2 + 125n_3$
	$6e_0 + 2e_1 + 3e_2 = n_0 + 5n_1 + 4n_2 + 6n_3$
6) $(e_0 + 6e_1 + 36e_2) \cdot 3 = n_0 + 6n_1 + 36n_2 + 216n_3$
	$6e_0 + 2e_1 + 3e_2 = n_0 + 6n_1 + 3n_2 + 4n_3$

$$\begin{cases} 6n_0 + 6n_1 + 6n_2 + 6n_3 = 0 \\ 6e_0 + 5e_1 + 3e_2 + 6n_0 + 5n_1 + 3n_2 + 6n_3 = 0 \\ 4e_0 + 5e_1 + e_2 + 6n_0 + 4n_1 + 5n_2 + n_3 = 0 \\ 6e_0 + 3e_1 + 5e_2 + 6n_0 + 3n_1 + 5n_2 + 6n_3 = 0 \\ 6e_0 + 2e_1 + 3e_2 + 6n_0 + 2n_1 + 3n_2 + n_3 = 0 \\ 3e_0 + 4e_1 + 3e_2 + 6n_0 + n_1 + 6n_2 + n_3 = 0 \end{cases}$$

$5n_3 = 3 \implies n_3 = 3 \cdot 5^{-1} = 3 \cdot 3 = 9 = 2$
