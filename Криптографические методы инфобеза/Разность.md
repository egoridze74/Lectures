#криптометоды 
$\vec{x} \oplus \vec{y}$ - под этой операцией подразумевается вычитание

$x_n', \dots x_1 \rightarrow \text{подстановка } \pi \rightarrow y_n', \dots y_1$

$\pi(x) = y$
$\vec{x} \rightarrow y$
$x' = \overline{x \oplus \alpha} \rightarrow y \oplus p$

$\alpha$ - входная разность на подстановку. Взять два входа, просуммировать их и будет **входная разность**
- $x \oplus x' = \alpha$ - разность на входе
- $\pi(x) \oplus \pi(x')$ - разность на выходе

### Разностная характеристика

$p_{\alpha \gamma}^{\pi} = P\{ \pi(x \oplus \alpha) \oplus \pi(x) = \gamma\}$ - разностная характеристика

Свойства разностной характеристики:
1) $p_{0, 0}^{\pi} = 1$
2) $p_{0, \gamma \in V_{n'} \setminus \{0\}}^{\pi} = 0$ - работает для любого преобразования
3) $p_{\alpha, 0}^{\pi} = 0$ - работает только для подстановки

- Нулевая разность на вход всегда переходит в нулевую
- Ненулевая разность на вход всегда переходит в ненулевую
