#оси 
Для разделения памяти между процессами (для предотвращения одновременного доступа к памяти и следующих за этим проблем с одновременным изменением, гонкой и т.д.) используются некоторые средства.

Примером этих средств являются **семафоры** (ранее про них говорили [[Механизмы синхронизации процессов|вот тут|]])

### Структуры
Ядро UNIX ведет таблицу, в которой отслеживаются все создаваемые в системе наборы семафоров. Каждая запись - набор семафоров, и запись содержит такие поля:
Структура `struct sem_perm`:
- имя - процесс, который создает набор семафоров, целое число
- идентификатор создателя
- идентификатор группы создателя
- идентификатор назначенного владельца
- идентификатор группы назначенного владельца
- права доступа
Остальные поля:
- sem_nsems - количество семафоров
- sems_base - указатель на массив семафоров
- sem_otime - время выполнения последней операции
- sem_ctime - время изменения параметров набора семафоров

Все это вместе составляет структуру `struct semid_ds`

В каждом семафоре из набора содержатся следующие данные:
Структура `struct sem`:
- semval - целочисленное значение данного семафора
- sempid - идентификатор процесса, который последним выполнял операцию с данным семафором
- semncnt - количество заблокированных на данном семафоре процессов, которые ждут его увеличения
- semzcnt - количество заблокированных на данном семафоре процессов, которые ждут его обнуления

Все эти структуры содержатся в `<sys/sem.h>`

### Связанные системные вызовы
- `int semget(key_t key, int num_sem, int flag);` - создание или открытие набора семафоров, где
	- key_t = int
	- num_sem - количество создаваемых семафоров
	- Если мы открываем набор семафоров, то num_sem и flag не важны
	- В качестве key можно использовать макрос `IPC_PRIVATE`. Используется для создания набора семафоров родственных процессов
	- На место флага можно вписать `IPC_CREAT`, как мы делали с очередями
	- `int fd = semget(5, 1, IPC_CREAT|0640);` - отдаст номер записи
	- `in fd  semget(5, 0, 0);` - отдаст `-1`
- `int semop(int fd, struct sembuf *op, int len);` - совершить операцию с семафором, где:
	- fd - берем из semget, номер пользовательского дескриптора
	- В случае удачи операции возвращается номер дескриптора, в случае неудачи `-1`
	- ```
		struct sembuf {
		  short sem_num; // - индекс семафора в наборе
		  short sem_op;  // - операция над семафором ( >0 - прибавляем это число, 
														  <0 - убавляем
														  =0 - сравниваем с нулем)
		  short sem_flg; // - флаг(и) операции. Если sem_flg=0 - процесс блокируется,
												   пока не выполним операцию,
												   Если IPC_NOWAIT - блокировки не 
												   произойдет (в <sys/ipc.h>),
												   Если SEM_UNDO - изменение, вызыванное 
												   semop, будет аннулировано по завершении 
												   данного процесса (если в процессе 
												   прибавили к семафору 1, то по его 
												   завершении вернется старое значение 
												   (отнимется 1))
		  short sem_num; // - индекс семафора в наборе
		  }
	  ```
	- len - количество операций, которые будут осуществлены при помощи semop (если хотим моенять сразу 3 семафора - len=3, над одним семафором можно произвести только 1 операцию)
	В случае успеха возвращает 0, в случае неудачи -1 (даже если одно изменение из нескольких не выполнится, вернет -1)
